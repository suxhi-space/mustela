## Version: 0.1.7-build2 (full change list)

_Everything in this hotfix. The release page uses the short version (0.1.7-build2.md)._

**A security and sync fix.** Your sign-in now lives in your system's keychain instead of the app's own storage, and saved themes (and other synced settings) can no longer be wiped when another device updates. Recommended for everyone.

### Security
- **Sign-in in the system keychain.** Windows Credential Manager, macOS Keychain, the Linux keyring (GNOME Keyring, KWallet), and Keystore-encrypted storage on Android. Moves over by itself the first time you open this version, no need to sign in again.
- Sync server keys are kept in the keychain too.
- The account details Android keeps for notifications while Mustela is closed are now encrypted.
- Link previews, pictures, GIFs and sounds can no longer be pointed at your home network (router, printer and so on).
- YouTube players in chat can't take over the Mustela window.
- Sync server: tighter limits on linking and slow connections, and its data file is private to the server.

### Improved
- **Call pop-out** follows the Title bar setting (Settings > Performance) on Mac and Linux. (Windows still has the system frame; being fixed in 0.1.8.)
- **Phones stay upright.** Mustela only turns sideways for a video in the viewer or a stream in a call. Tablets still turn freely.
- **Swipe between tabs** on phones and tablets: Friends, search, the search and pins panel, full profiles and the reactions list.
- **Swipe back in Settings** (yours, a server's and a channel's): swipe right on a page to go back to the list, and on the list to close Settings.
- **YouTube on phones.** The corner button on a YouTube video now opens it in the YouTube app, instead of a full screen that didn't work well sideways.

### Fixed
- **Saved themes disappearing on every device** when another device updated from an older version. Synced settings now merge piece by piece, so a device that doesn't know about something can't erase it anymore. If one of your devices is still on an older Mustela, the updated ones put your themes back.

### Good to know
- **Where your sign-in is kept now:** Windows Credential Manager, macOS Keychain, the Linux keyring (GNOME Keyring or KWallet), or on Android an encrypted file whose key is held by the phone's secure hardware (on most phones). It's no longer a plain file in Mustela's app folder, so copying or backing up that folder doesn't copy your sign-in. On macOS and Android other apps can't read it; on Windows and Linux it's protected by your login, but programs you run yourself could still ask for it, so the usual rule applies: don't run things you don't trust.
- **Linux without a keyring:** if no keyring is running (some lightweight desktops and window managers), Mustela can't use one, so your sign-in stays in Mustela's app data folder **unencrypted**, like in older versions. Anything running under your user account could read it. Install or start GNOME Keyring or KWallet and Mustela moves it in the next time it starts.
- **macOS:** after updating, your Mac may ask if Mustela can use its keychain. Click **Always Allow**. It may ask again after future updates until Mustela is signed by Apple. If you click Deny, Mustela can't sign you in until you restart it and allow it, or sign in again.
- **Locked keychain:** if your keychain is locked or its service isn't running when Mustela starts, Mustela tells you instead of signing you out. Unlock it and restart Mustela.
- **Signing out** removes that account's sign-in from the keychain.
- **Sync servers:** linking one sends your Stoat sign-in to that server once, so it can confirm who you are. It doesn't keep it, but only link servers you trust.
- **Android backups** never include Mustela's data, so your sign-in can't leave the phone that way.
