## Mustela 0.1.4-build1

Everything that changed since build4. Mostly fixes from people testing it, a proper go at the phone layout, and better search.

### Downloads

| System | File |
|---|---|
| Windows 10/11 | `Mustela_0.1.4-build1_windows_x64.exe` |
| macOS | `Mustela_0.1.4-build1_macos_universal.dmg` |
| Linux | `Mustela_0.1.4-build1_linux_amd64.AppImage` |
| Android | `Mustela_0.1.4-build1_android_universal.apk` |

> [!IMPORTANT]
> **Android:** if installing says "package conflicts", uninstall the old version once and install this one. That's from build4 being signed with a different key. Updates after this one install over the top like normal.

### Fixes
- Windows: sharing an app window showed a black screen. Fixed
- macOS: the screen recording permission window kept popping up even after allowing it. Mustela now checks first, and offers to open System Settings and restart
- macOS: apps now show up in the screen share picker once permission is given
- macOS: it said you were playing Minecraft when you weren't. Java, Python, Node and similar programs no longer count as games on their own
- Windows: profile animations were frozen if "Animation effects" is off in Windows settings. They play now. You can still choose to follow that setting under Performance
- The update notice could show a version that doesn't exist. Updates now go by the actual file names, not the tag
- The Windows installer now opens Mustela again when it's done updating
- The message hover bar got cut off by the message or date line above it. It now sits on top of everything
- Search did nothing on phones
- Search is quicker

### Calls
- Your own stream preview pauses while Mustela is in the background, so it's not eating your GPU
- "Muted for you" shows as a small badge on the person's tile and in their right-click menu
- "Hide people without video" now hides you too
- The old join screen is back on desktop
- DM call preview is bigger, sits a bit lower, has their banner blurred behind it, and resizes from its edge and corner

### Phones and tablets
- Settings, the profile editor and pop-ups stay clear of the status bar and the gesture bar or nav buttons
- Bigger buttons, switches and rows all round
- Android's font size setting no longer blows the layout up
- Settings rows put the label on top and the controls underneath, so nothing overlaps
- The profile editor scrolls as one full screen
- Profile cards slide up from the bottom, and scrolling pulls them up to full screen
- Full profiles scroll as one page with the tabs underneath
- Call controls are a sheet you pull up from the bottom. The bottom row is soundboard, mic, screen share, camera and hang up. Pull it up for deafen, call settings (mic, speaker, volume, noise suppression) and who's in the call
- Chat button in a call moved to a small icon in the top corner
- Hold on someone in a call for their options (volume, mute for me, their stream, profile)
- Picture-in-picture shows the stream or whoever's talking, not a squashed version of the app
- Inbox and "add friends" buttons are gone from the top bar on phones (inbox lives on your bottom card)
- The profile button in a DM opens their card instead of a cramped side panel
- Asks to turn on notifications the first time you open it
- Calls use the Web engine by default, so camera works out of the box
- Tablets held upright act more like a phone, sideways more like desktop

### Search
- Filter by who sent it, and by whether it has media, a link or a file
- Tabs for Messages, Media (a grid of pictures and videos), Links and Files
- Tap a result to see it with the messages around it, then **Jump to message**

### Favorites
- Favorite channels open right where they are, without switching to their server
- Make your own categories for favorites, colour them, drag channels between them
- Option to give Favorites its own button under Home that opens like a server. Turn it on in **Settings > Appearance**, or right-click the Home button
- Favorites have their own right-click menu: move to a category, remove, mute, notifications, or open it in its server

### Profiles
- Pronouns, using Stoat's own pronouns field, shown next to your name
- Friends don't show an "add friend" button anymore
- The full profile has the same "more" menu as the card

### Look
- New accounts start grey and dark, like Stoat. Existing setups don't change
- Gradient themes: Sunset, Ocean, Aurora, Forest, Candy, Ember, Midnight, Lavender, Citrus and Storm
- The gradient can tint the whole window, with a slider for how strong
- New backgrounds: gradient, and your picture blurred
- Panel see-through slider, so your background actually shows through, and a switch for the frosted blur behind panels
- Colours from your background picture: pick the picture swatch and the accent comes from it, like Windows and Android do with your wallpaper
- Pick any colour for a server folder
- Single emoji messages are a bit bigger

### Chat
- Mark as unread on any message, that message included
- Desktop notifications show who sent it with their picture, and where: "Mika (#general, Glass Garden)". On Windows, clicking one opens that chat

### Rich Presence
- Shows "Listening to" and "Watching" instead of always "Playing"
- Song progress bar
- Buttons from the game or app (like "Join game"), links only
- The little corner image and hover text

### Android building
- The signing key now lives in your home folder, so every new copy of the source signs the same way and updates install over each other
- Version codes count the build number, so a newer build always installs over an older one
- The build script asks for a package name if you want a separate install

### Sync server
- Version 1.3.0 keeps Rich Presence buttons. Older servers still work for everything else
