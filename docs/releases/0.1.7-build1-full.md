## Version: 0.1.7-build1 (full change list)

_Everything in 0.1.7, all test builds. The release page uses the short version (0.1.7-build1.md)._

**Mustela now opens straight away**, showing your servers, DMs and recent chats while it connects in the background. Android notifications work like a real chat app's (reply and mark as read right from the notification), every hold card on phones works the same way and keeps the message you're holding in view, search works like Discord's (a search screen on phones, "Find or start a conversation" and Ctrl+K on desktop), the mic and headphone menus have volume sliders, and there are saved themes, categories in server settings, a settings search that actually finds things, and a long list of polish and fixes for phones, tablets and desktop.

### Added
- **Instant start.** The app opens from what was on screen last time and connects in the background; unread chats are loaded ahead so they open straight away
- **Android notifications like a chat app's.** One per chat with pictures, grouped together, Reply and Mark as read, opens at the message, clears when you read it anywhere
- **Search like Discord's.** On phones, the search button opens People (friends and server members), Messages in your DMs, Media, Pins, Links, Files and Channels, with a Filter results menu. On desktop, "Find or start a conversation" (or Ctrl+K) jumps to anyone or anywhere
- **Mic and headphone menus like Discord's:** input and output volume right in the menu, your live mic level, the device list and an input profile (Voice isolation / Studio)
- Settings search finds every setting and takes you straight to it
- Saved themes: save your whole look under a name, window material included, and switch back any time (follows your account)
- Your recent photos in the + card, loading more as you scroll, as a grid or by date, with a scroll handle that shows the month (Android)
- Categories in Server settings > Channels: create, rename, reorder and move channels between them
- Rename server emoji
- Crop a server's icon and banner when you change them, like profile pictures
- Server and channel settings on phones open one page at a time, like your own Settings
- Double tap a message to react (phones and tablets), pictures included, with your own emoji
- Delete key in the emoji card (phones)
- Link previews show every picture of a post (X and Tumblr posts too)
- Streaming card on profiles: who's in the call, and a picture of the stream while you're in it
- Input sensitivity as one slider with your live mic level, like Discord's
- "Start voice call" in a DM's menu
